# Curso de Estructura de Datos con Java

Este repositorio contiene el material y código fuente del curso de Estructura de Datos utilizando Java como lenguaje de programación.

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio en tu equipo.
2. Asegúrate de tener instalado el JDK de Java en la versión 21 o 25.
3. Abre el proyecto en tu IDE preferido (por ejemplo, IntelliJ IDEA, Eclipse o VS Code).
4. Compila y ejecuta los programas según las instrucciones de cada unidad.

## Estructura del proyecto

El proyecto está dividido por unidades, siguiendo la organización del curso. Cada unidad agrupa los temas y ejercicios correspondientes para facilitar el seguimiento y el estudio.
